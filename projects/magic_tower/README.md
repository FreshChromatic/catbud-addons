# 貓芽魔幻之塔輔助模組

## 基礎教學
默認快捷鍵
"Z"  打開設置介面
"反引號"  對目標顏色外框/圖標 開啟/關閉 顯示路線
Shift + "反引號"  精確選擇重疊目標

默認情況下你會看到有三條不同顏色的線，分別為：
- 地獄傳送門 紫色
- 終界傳送門 青色
- 可探索路線 藍綠色

發現傳送門但路尚未開通時，會以內部 0.0～1.0 的探索優先分數比較可抵達的基岩出口，畫面不顯示分數文字。
分數代表探索優先度，不是成功機率；不再只因死路離門較近而建議走到死路。
待確認路線只畫到可站立的探索點，以原路線顏色為底，白色光帶向前掃過；
地獄門為紫底、終界門為青底。確認開通後恢復一般路線。
可在設定中關閉「待確認路線掃過動畫」以減少動態效果。

本層已發現的目標會保留，即使走遠、超出視距或所在區塊卸載，雷達標記也不會因此消失。
區塊重新載入後會核對目標是否仍存在；換層或離開副本時清空。
雷達「最大顯示距離」設為 0 可不限距離顯示已發現的目標，但不會擴大掃描範圍。

掃描模式預設為「自動偵測」，每次重新連線也會恢復預設。
僅在自動偵測異常時展開狀態頁的「手動控制」，選擇本次連線強制掃描或停止掃描；
這兩項操作必須再次確認，確認視窗預設選中「取消」，按 Esc 也會取消。
「恢復自動偵測」不需確認；重新開啟設定時手動控制會收起，但不會改變本次連線的掃描模式。

輔助觸發方式 - 就跟往常一樣選擇指定副本後它就會自己跑。
