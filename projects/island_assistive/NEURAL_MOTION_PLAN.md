# 從真人資料學習視角操作策略

狀態：已完成第一輪神經訓練基線、ONNX 匯出、重現檢查與幾何閉環比較；新版場景採集器通過 26.3 隔離驗證。尚未替換玩家版，補錄、神經策略遊戲內執行與正式驗收待完成。日期：2026-11-03。實作與重現方式見[神經視角策略](../mining_capture/learning/README.md)。

## 目標與責任

神經網路以當下場景及近期操作歷史，直接決定下一步視角動作，學習起步、持續轉向、減速、過衝修正、等待與重新瞄準。沿用目前的固定座標挖掘任務，先讓模型負責視角操作策略；挖掘按鍵、活動邊界與手動接管仍由既有功能負責。這不宣稱學會整套遊戲操作或任意任務。

模型執行時應由權重與當前觀測產生動作，不能檢索真人片段後重播，也不能只讓神經網路挑選 VARIED 的來源。現有 VARIED 1.0.3 保留為比較基準與可明確辨識的備援。

`CaptureRecorder` 已記錄時間、滑鼠事件、轉向前後事件、視角、眼睛位置、互動距離、目標命中、按住攻擊、聚焦與暫停狀態，以及目標選取形狀。它沒有完整記錄周邊方塊幾何／各目標區域的遮擋觀測；單一 body_hit 或 visible_hit 類型無法還原所有可見區域。新方案若要處理不同平台與局部遮擋，需補足這項觀測，不能從缺失資料推造。

## 執行順序

1. **整理可訓練的因果序列。** 對齊 mouse、turn、frames、world、trials 與伺服器事件，建立「當前及過去觀測 → 接下來的真人視角變化」。不跨試次、暫停、傳送或缺幀拼接，不把最終真人落點、未來形狀或未來命中結果放入輸入。保留原始資料、自然失誤及等待，分開處理技術不可用片段。以 session 分訓練與驗證，所有衍生切片留在同一組，正規化僅用訓練集估計。
2. **補足觀測規格。** 輸入採相對於眼睛／目標的幾何與視角、目標形狀、局部遮擋、目標更新／等待狀態及近期動作。避免靠絕對世界座標記住唯一場景。既有資料可先做目前場景的可行性訓練；缺失遮擋特徵不能填成「沒有遮擋」，需明確標示觀測版本，之後針對缺口補錄。未知 DPI 不阻擋以實際 yaw／pitch 變化作動作標籤的原型；若後續要輸出原始滑鼠位移，另驗證靈敏度與輸入換算。
3. **訓練第一個神經策略。** 建議從小型、單向的 RNN 加混合分布輸出的行為克隆開始，可參考 robomimic 的 BC-RNN-GMM。它以歷史與當下觀測預測下一時間步的雙軸轉向分布；保持與微調也是訓練行為，不能只訓練漂亮的轉向片段。先建立可重現的訓練／驗證與多種子結果，確認超過只輸出零動作、延續上一步等簡單基準。學習率、隱藏層與時間步長由開發資料選擇，不預先宣稱某組配置足夠。需要 Minecraft 的資料與環境接入，robomimic 並非開箱即用的 Minecraft 插件。
4. **測試模型自己的連續操作。** 從指定起點開始，每一步使用模型自己造成的新視角與命中狀態繼續預測；不能一直餵真人的下一幀再宣稱能實際操作。涵蓋多次重生、六方向薄片、局部遮擋、微移、等待、跨 yaw 邊界及未見過的相對站位。若短步輸出切換不連貫，再於開發集比較有持續潛變量的短動作序列或 ACT 類模型，不能用每幀額外亂數代替學習自然變化。
5. **針對實際失敗補示範。** 先看模型在哪些狀態失敗，再補真人從相似偏差狀態恢復的操作。由模型執行、真人接管產生的資料需區分執行來源；只有真人示範／修正動作能作真人標籤，不能把模型自己的動作假標成真人。此方向可參考 DAgger 的互動式模仿學習；沒有實際專家標註就不能聲稱完成 DAgger。
6. **凍結後才驗收與接入。** 舊研究已反覆查看的錄製先視為開發資料；正式結論需另一批事前封存的新真人資料及未參與選模型的場景。比較現有 VARIED、神經策略及真人：成功率、重瞄時間、實際破壞效率、連續動作自然度、重播感、運行成本與接管。自然度仍需真人盲評，不承諾一次模型就通過。新門檻於驗收資料解封前確定，保留現有規格與過去結果。

## 執行邊界與交付證據

神經策略產生原始角度動作，執行端負責時間步換算、合法角度、既定速度／加速度限制、活動範圍、實際射線攻擊條件與接管。安全層不應替模型挑完落點或合成主要轉向曲線。另記錄原始動作、限制後動作、限制介入比例及備援比例；大量由舊轉向器接管的結果不能算神經策略成功。超時、無效輸出及不適用狀態須可停止或明確切到備援。

最終至少交付資料清單與分組雜湊、觀測／動作定義與正規化參數、訓練設定及程式、學出的 checkpoint、可部署權重及對照結果。部署格式例如 ONNX，需在選定模型及 Java 執行方式後驗證匯出數值與推論延遲，現在不承諾匯出已成功。實際接入需證明關閉片段檢索後，仍由模型推論產生動作。

現在最先交付的是資料對齊／缺口報告與第一個可重現的神經訓練基線。先利用已有錄製，不先要求重錄整批資料。資料處理與離線訓練可在背景安排；啟動遊戲、前景擷取及真人修正錄製另依使用者電腦空閒時間安排。

## 方法來源

- [robomimic 的 BC-RNN 訓練範例](https://github.com/ARISE-Initiative/robomimic/blob/master/examples/train_bc_rnn.py)：包含 RNN 及 GMM 動作分布配置，是建議起點，不是本專案效果的證據。
- [DAgger 原始論文](https://proceedings.mlr.press/v15/ross11a.html)：說明策略造成的狀態分布偏移，以及在互動中蒐集專家標註的資料聚合方法。
- [ACT 原始論文](https://arxiv.org/abs/2304.13705)：動作序列生成的候選方向；機器人任務的結果不能直接視為 Minecraft 已驗證。
