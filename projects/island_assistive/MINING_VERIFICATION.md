# 自動挖掘驗證紀錄

日期：2026-10-30。主要遊戲版本：Minecraft 26.2，Fabric Loader 0.19.5，Fabric API 0.161.0+26.2，JDK 25。

**目前版本新增中斷選項、自動工具相容與帶加速度的轉向控制，並修正物品欄恢復時的攻擊鎖、連續挖掘重複等待冷卻及無進展判定；依要求，本輪只做編譯、打包及靜態檢查，沒有執行單元測試或遊戲內測試。以下紀錄屬更新前版本，不代表目前 JAR 已通過這些行為驗證。**

## 指定地圖

來源為 `C:/Users/User/AppData/Roaming/.minecraft/versions/26.2-Fabric_0.19.3/saves/tcpshield.test.catrealm.net`。驗證流程先建立獨立副本，使用開發客戶端的離線測試身分；沒有連入外部伺服器，也沒有使用 WhiteMeowGX 帳號。原存檔前後均為 65 個檔案，逐一比較 SHA-256，變更數為 0。

## 其他已通過項目

- 設定頁分類與選取按鈕、實際 `useItemOn`／Fabric 右鍵事件、攔截互動與座標持久化。
- 多面薄片的選取形狀與實際破壞。
- 開啟攻擊冷卻等待時，石頭仍可持續累積破壞進度。指定地圖使用其原有裝備，最後一輪為 14 ticks；先前隔離場景裸手驗證為 159 ticks。
- 20 次相同方塊狀態連續生成，持續超過 240 ticks，沒有因漏看空氣間隔而停止。
- 不可破壞目標暫停、取消選取、手動轉向接管、開啟介面中斷及釋放按鍵。
- 正在按住挖掘時，直接改變快捷欄選取槽位可觸發手動接管，涵蓋滑鼠滾輪造成的槽位變更。
- 正在按住挖掘時，客戶端玩家進入死亡狀態會暫停並釋放攻擊輸入；檢查後復原測試玩家生命值。
- 正在按住挖掘時真正離開世界，連線中斷事件清除工作階段與按鍵；卸載完成後驗證為停止狀態。
- 世界綁定拒絕其他世界的目標。
- 微移關閉時對不可見目標暫停。
- 強制微移場景在地圖副本內另建局部平台，不作為原布局測試：起點沒有可用落點，實際移動約 0.669 格後挖除 west=true 薄片，維持高度且未超出設定半徑；通往無支撐區域的路徑被拒絕。

測試程式結束前先離開世界，等待該地圖資源卸載完成，再關閉客戶端。最終整輪 `runClient` 正常結束；早期直接關閉的測試曾在所有行為檢查通過後遇到 `freetype.dll` 原生關閉崩潰，已修正測試結束順序。

## 建置與產物

1.21.11、26.1.2、26.2、26.3 全部建置通過，各有 30 個單元測試，失敗及錯誤均為 0。新增測試涵蓋負座標與世界資訊保存、損壞檔案備份、非法目標拒絕，以及轉向跨越 ±180 度與收斂行為。Java 使用專案 JDT 格式器。

26.2 另重跑原有生物提醒的整套遊戲內驗證，實體載入、音效、聊天室確認、名單操作與千隻生物掃描均通過。已確認目前使用的 26.2 Catbud Core 提供新增設定分類所需的 `SettingsAddon.extraRows` API。

正式 JAR 包含挖掘類別、輸入 Mixin 與設定／語系資源；不含驗證模組或測試類別。其他三版本完成建置與單元測試，新增挖掘流程的遊戲內結果僅對 26.2 作出驗證。

可安裝檔案：`out/catbud-island_assistive-26.2-1.0.2.jar`。

上述前版產物的 SHA-256：`89c218332b4e56bc007325c44765deb4b50ebb1859393a228694ee707e3cd9c6`。

## 重現

```powershell
.\gradlew.bat :projects:island_assistive:26.2:build
.\gradlew.bat :projects:island_assistive:26.2:runClient -PverifyIslandMining '-PminingMap=C:/Users/User/AppData/Roaming/.minecraft/versions/26.2-Fabric_0.19.3/saves/tcpshield.test.catrealm.net'
```

若出現世界實驗性設定提示，需要確認載入副本。每次執行均建立新的地圖副本，測試不會直接開啟來源地圖。報告：`versions/26.2/build/verification-island-mining/mining-report.txt`；畫面：同目錄 `screenshots/island-mining-settings.png`。
