# 空島輔助（island_assistive）

Fabric 客戶端模組，提供附近生物名單偵測、持續音效提醒及固定座標自動挖掘。支援 Minecraft 1.21.11、26.1.2、26.2、26.3，需另外安裝相同 Minecraft 版本的 Catbud Core 與 Fabric API。新增挖掘功能的遊戲內驗證以 26.2 為基準。

## 使用

1. 開啟 Catbud Core 設定（預設 Z），選擇「空島輔助」。
2. 「生物提醒」預設關閉，需手動啟用並套用設定。
3. 預設名單只有殭屍村民（`minecraft:zombie_villager`），預設三維偵測距離為 256 格，可調整 16–256 格。
4. 在「狀態」開啟「生物提醒名單」，新增、選取編輯或刪除規則，再儲存名單。種類與自訂名稱可組合比對；名稱支援完全相同或包含文字。
5. 啟用後先用 2 秒建立基準；已存在的目標只合併通知。之後新發現的目標立即播放音效，並每 5 秒重播。
6. 點擊聊天室「停止此提醒」確認單項，或「停止以上全部提醒」確認該訊息及之前的提醒。後來新發現的目標仍會持續響鈴。

同一隻生物在同次連線中不會因走出範圍或暫時卸載而重複提醒。目標死亡、離開或切換維度後，待確認提醒仍保留；關閉功能或斷線會停止音效並清除暫存。修改名單或距離會重新建立基準，既有待確認提醒不會被清除。

名單清空後會保持空白，重新啟動不會自動補回殭屍村民。設定與名單分別儲存於 `config/catbud/addons/island_assistive.json`、`config/catbud/addons/island_assistive_watchlist.json`。無法讀取名單時會顯示警告；再次儲存前會備份原檔。

指定的 `regen_current_chunk.ogg` 已隨模組打包，無須另裝來源資源包。設定頁提供音量與試聽，仍遵守遊戲音量設定。

## 偵測限制

「新發現」指初始掃描後首次偵測到目標，可能是剛生成，也可能是既有生物剛進入客戶端追蹤範圍。純客戶端無法確認伺服器上的出生原因，也無法偵測伺服器尚未傳送的生物。256 格是篩選上限，不會擴大伺服器實體追蹤距離。

預設偵測真正的生物實體，排除玩家、盔甲座與文字展示。以其他實體顯示名稱的伺服器特殊生物需要額外適配。

## 固定座標自動挖掘

1. 開啟 Catbud Core 設定，選擇「空島輔助 → 自動挖掘」。
2. 點擊「選取一格方塊」，回到遊戲後右鍵目標。該次右鍵只記錄座標，不放置方塊或操作容器；Esc 或開啟介面可取消，30 秒後也會取消。
3. 按需要調整微移與轉向設定並套用。預設允許微移，範圍為啟動站位周圍 0.5 格，可調整 0.125–1 格；預設轉向速度每秒 180 度。
4. 站穩後點擊「開始／恢復」，或按預設的 Delete 開關。可在遊戲控制設定中更改「開始／停止自動挖掘」；已有自訂綁定會沿用。
5. 只挖指定座標目前生成的方塊，不限制方塊種類。空氣時等待；sculk_vein 等薄片依實際選取形狀瞄準，原地不可達才嘗試有支撐的局部微移。

目標與伺服器／本機世界、維度綁定，另存於 `config/catbud/addons/island_assistive_mining_target.json`；損壞檔案不會產生可執行目標，重新選取時會備份原檔。執行狀態不保存，重新登入後需手動開始。生物提醒與挖掘功能可獨立運作。

預設在啟動或中斷後恢復挖掘前等待一次攻擊冷卻，使用原版點擊與按住流程；同一輪連續挖掘遇到新方塊或自動換工具時不會重新等待攻擊冷卻。原版切換不同工具時仍會重新計算該方塊的破壞進度。關閉物品欄後，重新開始挖掘時會解除原版介面留下的攻擊鎖。準星實際命中指定方塊才會挖掘，不自動攻擊擋住視線的生物。請停用其他自動點擊功能，避免兩者同時控制攻擊鍵。

無進展判定會追蹤細部破壞進度與客戶端成功破壞事件，涵蓋瞬間挖碎後同座標生成相同方塊的情況；這些事件不代表伺服器已確認破壞。若持續一秒沒有進度且原版已沒有正在破壞的方塊，會釋放攻擊並重新開始一次；仍無進展才會依原有逾時限制暫停。

實際手動移動、轉向、攻擊、快捷欄按鍵或滾輪會停止控制。伺服器自動工具造成的槽位切換不算手動操作；介面內的點擊與輸入也不算接管。死亡、斷線、換維度、超出活動範圍或長時間無進展仍會停止或暫停，需要手動恢復。

中斷行為可分別設定，暫停條件解除後會自動恢復同一目標：

| 選項 | 預設 | 行為 |
| --- | --- | --- |
| 物品欄／容器開啟時暫停 | 開 | 開啟物品欄、箱子等容器時釋放操作，關閉後繼續 |
| 其他介面開啟時暫停 | 關 | 預設在聊天、設定、暫停選單等介面後繼續執行 |
| 持續使用物品時暫停 | 關 | 預設保持腳本執行；原版禁止同時挖掘時等待物品使用結束 |
| 視窗失去焦點時暫停 | 關 | 預設切到其他視窗仍繼續；開啟此選項後返回遊戲自動恢復 |

背景挖掘使用玩家本體的實際射線與原版破壞流程，不把遊戲攻擊點擊傳入正在操作的介面。腳本執行期間，允許背景執行的介面／失焦情境也會讓單人世界繼續運作；停止腳本後恢復原版暫停規則，不修改全域暫停偏好。載入資源等原生世界暫停仍會等待恢復。

轉向按畫面幀更新，保留雙軸速度並限制加速度，以柔和起步與收尾取代直接切到固定轉速。支援 Tweakeroo 自由鏡頭，本體可持續瞄準、挖掘與安全微移，鏡頭保持獨立。微移不跳躍、不拆除鄰近方塊、不使用完整尋路；有支撐且可達時才移動，完全遮蔽的面不保證可挖。短暫方塊更新或遮擋會先重新尋找落點，持續不可達才暫停。

## 開發與驗證

使用 JDK 25：

```powershell
.\gradlew.bat :projects:island_assistive:26.2:build
.\gradlew.bat :projects:island_assistive:26.2:runClient -PverifyIslandAssistive
```

將版本替換為其他支援版本可執行相同驗證。`build` 執行時間控制、基準、名單、去重、批次確認與持久化測試；遊戲內驗證會建立獨立測試世界，檢查實體事件、音效資源、實際聊天室點擊、名單操作與千隻生物掃描成本，並輸出報告及畫面至該版本的 `build/verification-island-assistive/`。驗證程式不會打包進玩家使用的 JAR。

可安裝檔案輸出至 `out/catbud-island_assistive-<minecraft>-1.0.2.jar`。

26.2 挖掘驗證使用獨立測試模組，不會打包進正式 JAR：

```powershell
.\gradlew.bat :projects:island_assistive:26.2:runClient -PverifyIslandMining
.\gradlew.bat :projects:island_assistive:26.2:runClient -PverifyIslandMining '-PminingMap=C:/Users/User/AppData/Roaming/.minecraft/versions/26.2-Fabric_0.19.3/saves/tcpshield.test.catrealm.net'
```

傳入 `miningMap` 會先複製地圖到該版本的 `build/verification-island-mining/saves/`，不直接開啟或寫入來源存檔。使用開發客戶端的離線測試身分，不需要正式帳號或外部伺服器。原地圖布局的六方向檢查使用站位 `-3575.701 67 -3575.562`、目標 `-3576 65 -3576`；後續強制微移檢查僅在副本內另建局部測試平台。報告輸出至 `build/verification-island-mining/mining-report.txt`，畫面位於同目錄的 `screenshots/`。

可加上 `-PautoClickerReference=<26.2 Auto-Clicker JAR>`，在隔離環境對照其 Cooldown 與 Mob Mode 四種組合；這不代表外部伺服器插件的行為。

完整結果見[驗證紀錄](VERIFICATION.md)。
