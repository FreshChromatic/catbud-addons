# 1.0.2 修訂 2

支援 Minecraft 1.21.11、26.1.2、26.2、26.3。模組版本維持 `1.0.2`，本次發布標籤為 `v1.0.2-r2`。

## 魔幻之塔修正

- 遠距離傳送門找不到已載入入口時，會搜尋可達的探索或地形載入邊界；地形載入後重新接續路線。
- 箱子等快捷鍵目標使用相同的探索邏輯，避免優先停在離目標較近的死路牆前。
- 所有未確認路線都支援白色流光，路線終點留在可站立的位置，避免最後一段線穿牆。
- 探索搜尋不再受原本 96 格步行距離限制，仍保留搜尋節點數上限。

## Core 更新

- 新增同版本修訂更新，支援 `r2`、`r3` 等後續修訂。
- 相同版本以 SHA-256 判斷內容；只更新內容有變更且修訂較新的模組。
- 更新畫面與提醒顯示修訂號；略過或延後某個修訂不影響下一個修訂提醒。
- 保留簽章驗證、核准重查、關閉遊戲後安裝，以及整批還原功能。

## 安裝方式

下載對應 Minecraft 版本的 `catbud-core-<Minecraft>-1.0.2-r2.jar`，以及需要的附加模組，關閉遊戲後替換 `mods` 中原有的對應 JAR，避免同時保留兩份相同模組。附加模組共用一份獨立 Core。

**舊版 Core 無法辨識修訂標籤，本次首次更新需要手動下載替換 Core。** 後續修訂須經雲端管理端匯入及核准後，支援修訂的客戶端才會收到更新。這次 GitHub 發布不代表正式雲端已部署或核准此修訂。

請保留下載檔名中的修訂號，讓更新器正確辨識已安裝修訂。

附件包含 Core、魔幻之塔、公共傳點的四版本安裝檔，共 12 個 JAR，另附簽署清單與簽章。公共傳點功能本次未調整。

## 驗證

- 四個 Minecraft 版本的完整 Java 建置、測試與安裝檔打包通過。
- 更新器 37 項測試及雲端相關 24 項回歸測試通過。
- 已驗證修訂簽署、變更判斷、安裝、重複更新略過及還原；尚未進行正式伺服器上的遊戲實測。
